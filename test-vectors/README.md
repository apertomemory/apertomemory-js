# Test vectors

`amem-testvector-001.json` and `amem-testvector-002.json` are the
official test vectors of the specification, copied verbatim from the
[main repository](https://github.com/apertomemory/apertomemory/tree/main/test-vectors).

`interop-python-export.amem` is a vault (3 objects, 2 scopes) exported
by the Python reference implementation (`apertomemory` 0.1.3 on PyPI),
used by the cross-implementation interoperability test. Its passphrase
is `interop test passphrase` - it contains no real data.
